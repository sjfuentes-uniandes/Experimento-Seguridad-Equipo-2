# Experimento-Seguridad-Equipo-2
Este repositorio contiene el código de los microservicios necesario para ejecutar el experimento de seguridad

## Levantar los servicios:
Ejecutar el siguiente comando para iniciar los servicios con docker.

```
docker-compose up --build
```

## Ejecutar un cliente de prueba:
Ejecutar el siguiente comando para ejecutar el script con los casos de prueba.

```
python test_client.py
```
